Как открыть: двойной клик по index.html, затем выбрать нужный Task.

Task 1
Bootstrap row и col-md делят поля на колонки с 768px. На телефоне поля идут
в одну колонку. form-floating даёт подписи From и To внутри полей.
btn-check - настоящие radio, оформленные как кнопки. Одинаковое name
позволяет выбрать только один вариант. fieldset и legend называют группу.
input-group объединяет +7 и телефон. form-switch оформляет SMS-переключатель.
Clear имеет type=reset. Значений value и checked по умолчанию нет, поэтому
сброс действительно очищает поля. Выбор пассажиров возвращается к подсказке.
flex-direction: column-reverse меняет видимый порядок кнопок на телефоне.
Порядок в HTML и порядок Tab остаются Clear, Find trains.

Task 2
required запрещает пустое поле. type=email проверяет формат email.
Адрес не обязан принадлежать astanait.edu.kz: в задании нужен любой корректный email.
type=url требует полный URL, например https://github.com/name.
min и max задают границы. step=1 допускает целые числа.
У времени step измеряется в секундах: 1800 секунд = 30 минут.
У взноса step=500 допускает 0, 500, 1000 и так далее до 5000.
minlength и maxlength задают длину текста. maxlength не даёт ввести лишнее.
У пустой option значение value="", поэтому required её отвергает.
Одинаковое name у radio объединяет варианты опыта.
:user-invalid показывает ошибки после взаимодействия или попытки отправки.
.invalid-feedback обычно скрыт Bootstrap; наш CSS показывает его при ошибке.
Проверку выполняет браузер, в HTML-файлах нет JavaScript.
POST не помещает пароль в адресную строку. Сервер регистрации в задании не реализован.

Task 3
label for должен совпадать с id поля. id должен быть уникальным.
name нужен для отправки значения; id сам по себе значение не отправляет.
Радиокнопки seating имеют одинаковое name и разные value.
button type=submit работает через Tab и Enter, обычный div так не работает.
type=number не допускает текст, type=date даёт календарь, type=tel - телефонную
клавиатуру на телефоне. type=tel сам не проверяет определённый формат номера.
Комментарии необязательные. Все девять исходных полей сохранены.

Проверка: Tab - переход, Shift+Tab - назад, Space - checkbox/radio,
стрелки - выбор radio, Enter - отправка. При неверных данных браузер блокирует форму.
